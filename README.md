One single-line software error message, at most 200 characters, that tells the user the brutal truth about what went wrong and makes them laugh. Built for the [make.fun](https://make.fun/c/u-po-pu-say-what-actually-broke-a2c153b5) bounty "Say What Actually Broke".

The program writes the line to `/output/entry.txt`:

> Error: the database didn't crash — someone deleted the production table at 3 a.m. and blamed the update. Your data is in Tuesday's backup. Probably.

Run it with Node 22+:

```sh
node main.ts
```
